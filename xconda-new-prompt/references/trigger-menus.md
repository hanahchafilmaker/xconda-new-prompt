# 트리거 단독 입력 시 출력 메뉴 (구 §3)

> 이 파일은 SKILL.md에서 분리된 상세 규칙입니다. SKILL.md의 라우팅 표가 이 파일을 가리킬 때 엽니다.
> 규칙 내용은 원본 그대로이며 위치만 옮겼습니다.

## 3. 트리거 단독 입력 시 — 아래 메뉴를 그대로 출력

사용자가 "엑스콘다" 또는 "XCONDA"만 딱 입력하면, 설명이나 인사 없이 **아래 메뉴를 그대로** 출력하고
응답을 끝냅니다. 프롬프트를 미리 만들지 않습니다.

### 한글 트리거일 때

```
════════════════════════════════════════════
🎬 XCONDA NEW 프롬프트 에디터
   총괄 · 촬영 · 조명 · 미술    [Seedance 2.5 기준]
════════════════════════════════════════════
✅ 작동 중입니다.

▶ 최소 조건 — 이것 하나면 시작됩니다
   "누가 / 어디서 / 무엇을" 한 줄
   예) 눈밭에서 여자가 체인소로 좀비 무리와 싸운다

▶ 창에 넣을 수 있는 것 — 있는 것만 넣으세요
   ① 글       시나리오 · 대본 · 상황 설명 · 느낌 한 줄
   ② .txt     기존 프롬프트 (고치기 / 다시 만들기)
   ③ 이미지   콘티 · 스토리보드 → 구도와 동선만 따옵니다
   ④ 이미지   캐릭터 얼굴 (인물당 1장) → 얼굴 고정
   ⑤ 이미지   의상 · 로케이션 → 옷과 공간 고정
   ⑥ 영상     카메라 무브 레퍼런스 · 화이트모델 블로킹
   ⑦ 오디오   배경음 · 목소리 톤
   ⑧ 글       핵심 소품 (재질 · 색 · 크기 · 무게)

▶ 말씀해주시면 더 정확해집니다 (없으면 기본값)
   길이(기본 15초 · 최대 30초) · 컷 수 · 톤/느낌
   · 원테이크인지 멀티컷인지 · 배경 인물 유무
   · 음악 유무(기본 없음) · 화면비(기본 16:9)

▶ 2.5 사양
   · 단일 생성 4~30초 · 연장으로 그 이상
   · 레퍼런스 50개 (이미지 30 · 영상 10 · 오디오 10)
   · 단 50개는 천장이지 목표가 아닙니다
     → 권장 이미지 8 · 영상 5 · 오디오 5 이내
   · 얼굴 이미지는 인물당 1장 (여러 장이면 얼굴이 뭉개집니다)

▶ 결과물
   한국어·영문이 나란히 놓인 편집기 .html 한 개
   왼쪽 한국어는 눈으로 확인하는 용도, 오른쪽 영문이 실제로 붙여넣는 것

▶ 모드 — 안 고르셔도 넣으신 자료를 보고 자동 판단합니다
   [1] 새로 만들기        [2] 기존 프롬프트 고치기
   [3] 스토리보드로 만들기  [4] 전체 다시 만들기
   [5] 위임 레벨 바꾸기
   [6] 영상 연장하기 (30초 뒤를 이어서)
   [7] 특정 구간만 고치기 (타임스탬프 편집)

────────────────────────────────────────────
💡 바로 시작: "엑스콘다 [장면 설명]"
   자료가 부족해도 됩니다 — 일단 만들어 보여드리고
   무엇을 더하면 좋아지는지 알려드립니다.
════════════════════════════════════════════
```

### 영문 트리거일 때

이 경우 이후 모든 출력을 영어로 냅니다. 단 편집기 2열 구조는 유지하되, 왼쪽=사용자 모국어(영어),
오른쪽=실사용 영문으로 두고 두 열의 내용을 동일하게 맞춥니다.

```
════════════════════════════════════════════
🎬 XCONDA NEW PROMPT EDITOR
   Showrunner · DP · Gaffer · Production Designer
   [Seedance 2.5]
════════════════════════════════════════════
✅ Active.

▶ MINIMUM — one line is enough
   "who / where / doing what"

▶ WHAT YOU CAN DROP IN — only what you have
   ① text  script · scene description · just a feeling
   ② .txt  an existing prompt (fix / rebuild)
   ③ image storyboard → framing and blocking only
   ④ image character face (ONE per person) → identity lock
   ⑤ image wardrobe · location → outfit and space lock
   ⑥ video camera move reference · white-model blocking
   ⑦ audio background track · voice tone
   ⑧ text  key prop (material · color · size · weight)

▶ HELPFUL BUT OPTIONAL (defaults apply)
   duration (default 15s, max 30s) · beat count · tone
   · oner or multi-cut · crowd · music (default none) · aspect (default 16:9)

▶ SEEDANCE 2.5 SPECS
   · 4-30s single pass, longer via extension
   · 50 references (30 image / 10 video / 10 audio)
   · 50 is the ceiling, not the target → recommended 8 / 5 / 5
   · ONE face image per character

▶ MODES — auto-detected from what you upload
   [1] New  [2] Fix  [3] From storyboard  [4] Regenerate
   [5] Delegation level  [6] Extend  [7] Edit a time range

────────────────────────────────────────────
💡 Quick start: "XCONDA [scene description]"
════════════════════════════════════════════
```

### 트리거 + 내용이 함께 온 경우

메뉴를 건너뛰고 즉시 실행합니다.

| 입력 | 실행 |
|---|---|
| "엑스콘다 눈밭 액션씬" | 1번(새로 만들기) |
| .txt 파일 첨부 + 트리거 | 2번(기존 프롬프트 고치기) |
| 스토리보드 이미지 + 트리거 | 3번(스토리보드로 만들기) |
| "다시 만들어줘" / "regenerate" | 4번(전체 다시 만들기) |
| 숫자 1~7만 입력 | 해당 모드 진입 |

### 가장 확실한 입력 조합 (S급)

보드 프롬프트 + 스토리보드 이미지 + 캐릭터 얼굴 1장 + 의상 전신 + 소품 락

- **글이 책임지는 것**: 컷 순서·구도·동선·액션·타이밍
- **이미지가 책임지는 것**: 얼굴·의상·질감·시대 고증

얼굴은 글로 고정되지 않고, 컷 순서는 이미지로 고정되지 않습니다. 예: 시대·왕조는 이미지가
소유합니다. 글에 왕조명을 박고 이미지가 다른 시대를 보여주면 모델이 둘을 섞습니다. 확신이 없으면
왕조명을 쓰지 않고 "시대 고증은 전적으로 @Image1의 복식을 따른다"로 위임합니다.

### 다른 툴의 보드 프롬프트를 받았을 때 — 그대로 붙여넣지 않는다

다른 툴의 보드 프롬프트에는 이미 조명·얼굴·스타일 묘사가 들어 있습니다. 이미지와 함께 넣으면
같은 대상을 두 곳에서 지시해 충돌합니다. 받는 즉시 아래처럼 분해해서 재배치하고, 정리 후
**무엇을 걷어냈는지 한 줄로 보고**합니다.

| 보드 프롬프트 속 내용 | 재배치할 곳 |
|---|---|
| 컷 순서·구도·동선·액션·타이밍 | 08번 [타임라인] |
| 카메라 무브·화각·핸드헬드 | 04번 [옵틱스·카메라] (컷 안이 아니다) |
| 얼굴·의상 묘사 | 삭제 (@Image가 소유) |
| 컷별 조명 묘사 | 전부 걷어 03번 [시네마틱 셋업] 한 곳으로 |
| 스타일·화질 문구 | 09번 [스타일 & 출력] 한 곳으로 |
| 보드 자체 네거티브 | 포지티브 락으로 뒤집어 10번으로 (§6 참고) |
| 패널·그리드 표현 | 삭제 + 잔류 네거티브에 "그리드 금지" 추가 |
