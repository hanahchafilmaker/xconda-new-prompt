# 소품 락·연기 지문·컷 길이 산정 (구 §11)

> 이 파일은 SKILL.md에서 분리된 상세 규칙입니다. SKILL.md의 라우팅 표가 이 파일을 가리킬 때 엽니다.
> 규칙 내용은 원본 그대로이며 위치만 옮겼습니다.

## 11. 소품 락 · 연기 지문 — 짧지만 중요한 두 가지

**소품 락**: 이미지가 없는 핵심 소품은 형태+무게+사용 제약을 함께 씁니다. 무게를 쓰지 않으면
모델이 무엇이든 가볍게 휘두릅니다.
예) "낡은 산업용 체인소, 60cm 바, 서리가 앉은 주황색 바디, 긁힌 금속. 두 손으로 들어야 할 만큼
무겁다 — 스윙마다 무게에 몸이 끌려간다. 11컷 내내 동일 형태."
체크: 재질·색·크기 / 마모 상태 / 무게가 동작에 주는 제약 / "N초 내내 동일 형태" 명시 여부.

**연기를 근육으로 번역**: 감정을 형용사로 쓰지 않고 몸의 움직임으로 씁니다.
- ❌ "슬퍼 보인다" → ⭕ "시선이 테이블로 떨어지고, 턱이 굳고, 대답 전에 한 번 침을 삼킨다"
- ❌ "화가 났다" → ⭕ "잔을 쥔 손가락 관절이 하얘지고, 호흡이 짧아지고, 시선이 그녀를 떠나지 않는다"

말더듬·망설임은 목소리만으로 쓰면 성대모사처럼 보입니다. 몸이 같이 더듬어야 합니다. 기본은
절제입니다 — 대부분의 경우 속삭임이 고함보다 잘 연기합니다.

### 8-16. 컷 길이는 대사·액션 밀도로 정한다 (러닝타임 산정)

컷 길이를 감으로 짧게 잡으면 배우가 속사포로 말하거나 동작이 뭉개진다. 아래 하한을
지킨 뒤, 위치별 처방(§8-4)을 얹는다. 러닝타임(총 길이)은 이렇게 잡은 컷 길이의 합이다.

**대사 컷** — 대사 읽는 시간을 먼저 확보한다.
- 한국어 대사 시간 ≈ (공백 뺀 글자수 ÷ 4.5)초. 급박한 외침은 ÷6, 무게 있는 대사는 ÷3.5.
  (블로킹 보드의 `speaking()`은 관대하게 ÷7로 잡으니, **손으로 쓸 때는 ÷4.5**로 여유를 둔다.)
- 한 컷에 대사가 둘 이상이면 각 대사 시간을 **더한다**(겹쳐 말하지 않는 한).
- 컷 길이 = 대사 시간 합 + 앞뒤 호흡 0.5초. 여기에 그 컷의 동작 시간을 얹는다.
- 예) 대한 "신입 보고서 봤지? …그래서 만들었어"(공백 뺀 24자) ≈ 24÷4.5 ≈ 5.3초.
  민희 "그건 또 뭐예요"(7자) ≈ 1.6초. 둘이 순차면 최소 5.3+1.6+0.5 ≈ 7.4초 → 8초로 잡는다.
  이걸 5초로 잡으면 배우가 숨도 안 쉬고 말한다.

**액션 컷** — 동작 전환 1개당 약 1초를 센다.
- "검은 손이 다리를 휘감음 → 대한이 끌기 → 민희가 버티기 → 박수가 부적 던짐 → 부적이
  날아옴" 처럼 전환이 5~6개면 겹침을 감안해도 5초는 필요하다. 3.5초에 넣으면 급하다.

**회상·감정 인서트** — 스치듯 지나가지 않게 최소 2초. 1초대는 관객이 못 읽는다.
글콘티에 "0.5초 플래시"처럼 적혀 있어도 그대로 쓰지 않는다 — 씨댄스 타임스탬프 드리프트가
±0.3초라 0.5초는 통째로 사라진다. **최소 1.2초로 뽑아 편집에서 잘라 쓰도록** 안내하고,
원본 길이를 바꿨다는 사실을 브리핑에 적는다.

**걷기 컷** — 도착 거리(m) ÷ 보행 속도로 소요 시간을 검산한다. 일반 보행 ≈ 1.2~1.4 m/s,
"걷다가 속도 줄임"은 더 느리다. 10m를 4초(2.5 m/s)로 잡으면 뜀박질이 된다 → 걷기면 늘린다.

정리 순서: ① 각 컷의 대사 시간·동작 시간으로 **하한**을 잡고 → ② §8-4 위치별 처방으로
미세 조정 → ③ 합이 총 길이. 30초(2.5)를 넘으면 §11 분할.
