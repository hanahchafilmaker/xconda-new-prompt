# 창작 번역표 — 느낌을 카메라·조명·색 언어로 바꾸는 사전

이 문서는 "어떤 단어를 고를지"의 사전이다. 프롬프트를 쓰기 전에 한 번 훑어보고,
막상 쓸 때 여기서 값을 그대로 가져다 쓴다. 값 자체를 바꾸고 싶으면 이 파일을 고치되,
바꾸면 검수(§16)의 기준값도 같이 바뀐다는 걸 기억한다.

---

## 1. 느낌 → 카메라

| 느낌 | 선택 사양 | 관객이 느끼는 효과 |
|---|---|---|
| 답답하다·몰린다 | 84° + 타이트 + 로우 앵글 | 공간이 휘어 압박감이 생긴다 |
| 멋있다·고급스럽다 | 29° + 얕은 심도 | 배경이 녹고 인물만 남는다 |
| 남의 일 같다·차갑다 | 18° 망원 고정 | 멀리서 훔쳐보는 느낌, 이입이 줄어든다 |
| 불안하다·취했다 | 더치 앵글 + 핸드헬드 | 기울고 흔들려 안정감을 잃는다 |
| 압도된다 | 로우 앵글 | 올려다보면 인물이 커 보인다 |
| 초라하다·위축된다 | 하이 앵글 | 내려다보면 작고 약해 보인다 |
| 운명적이다 | 버드아이 탑다운 | 신의 시점 |
| 각오한다 | 슬로 푸시인 | 천천히 다가가며 관객이 숨을 참는다 |
| 끝났다·여운 | EWS + 슬로 풀아웃 | 뒤로 빠지며 이야기가 닫힌다 |
| 같이 뛴다·몰입 | 트래킹 / 핸드헬드 팔로우 | 인물 옆에서 함께 움직인다 |
| 등장이 강렬하다 | 오빗 + 로우 앵글 | 주위를 돌며 주인공으로 만든다 |
| 발견한다 | 랙 포커스 | 초점이 옮겨가며 시선을 끌고 간다 |
| 상황이 다 보인다 | 딥 포커스 + 47° WS | 앞뒤가 다 선명해 정보를 동시에 준다 |
| 다큐 같다 | 63° + 핸드헬드 | 사람 눈에 가까운 화각 + 미세한 흔들림 |
| 꿈 같다 | 107° + 저대비 + 보케 | 원근이 과장되고 빛이 번진다 |
| 긴장이 조인다 | 컷 길이 단축 + 타이트 CU 반복 | 컷이 짧아질수록 심박이 오른다 |
| 숨 막힌다(정적) | 고정 + 롱테이크 | 카메라가 안 움직이면 도망갈 곳이 없다 |

## 2. 화각 앵커 9단계 — 이 값만 쓴다

(mm 열은 이해를 돕는 참고용이며, 프롬프트 문장에는 쓰지 않는다. 화각(°) 값만 쓴다.)

| FOV | 대략 mm | 쓰임 |
|---|---|---|
| 180° | 피시아이 | POV, 꿈 |
| 107° | 14-16mm | 거대한 실내, 웅장한 확립 |
| 84° | 20-24mm | 확립, 그룹 블로킹 |
| 63° | 28-35mm | 관찰, 르포, 다큐 |
| 47° | 40-50mm | 범용 확립, 미디엄 (★ 미디엄 대화 컷의 기본값) |
| 29° | 75-85mm | 미디엄 분리, 대화 바스트 |
| 18° | 100-135mm | 클로즈 포트레이트, 정체성 보존 |
| 12° | 180-200mm | 손, 물체 |
| 8° | 300-400mm | 극단적 압축, 관찰 |

- **중간값(23°, 50° 등)을 만들지 않는다.** 습관적으로 `50°`를 쓰지 않도록 주의한다 —
  50°는 이 9단계 앵커 밖이라 검수(§16)가 빨간불로 잡는다.
- fps · ISO · 셔터스피드는 Seedance가 해석하지 못하므로 쓰지 않는다.
  대신 얕은 심도 / 딥 포커스 / 랙 포커스, f값(조리개)은 허용된다.

## 3. 카메라 어휘 (영문 표기)

**샷 사이즈**: ECU / CU / MCU / MS / WS / EWS

**앵글**: eye-level · low angle · high angle · dutch angle · bird's eye view

**무브먼트**: slow push-in · slow pull-out · pan left(right) · tilt up(down) ·
tracking shot · orbit shot · handheld follow · locked-off shot

**포커스**: shallow depth of field · deep focus · rack focus from A to B

---

## 4. 컷 위치별 기본 처방 (15초 멀티컷 기준)

| 구간 | 역할 | 기본 처방 |
|---|---|---|
| 0~1.5초 | 훅 | ECU 고정 또는 디테일 인서트. 소리 먼저 |
| 1.5~4초 | 확립 | MCU + 슬로 푸시인 |
| 4~9초 | 전개 | WS ↔ 트래킹 교차. 무브 다양화 |
| 9~12초 | 피크 | 로우 앵글 / 다이나믹 와이드 / 핸드헬드 |
| 12~15초 | 여운 | EWS + 슬로 풀아웃 |

- 말더듬·망설임·긴 호흡이 있는 대사 구간은 0.5초 늘린다.
- 같은 무브를 3연속 쓰지 않고, 고정 컷을 최소 2개 섞는다.
- 30초·45초처럼 더 긴 멀티컷은 이 5단계 비율을 그대로 늘려 잡는다
  (예: 30초면 훅 3초·확립 8초·전개 10초·피크 6초·여운 3초 식으로 비례 배분).

## 5. 느낌 → 조명

| 느낌 | 처방 |
|---|---|
| 따뜻하다·안전하다 | 소프트 키 + 강한 필 + 3200K |
| 밝고 경쾌하다 | 하이키. 그림자를 지운다 |
| 무겁다·숨긴다 | 로우키. 필 제거, 얼굴 반쪽이 어둠에 |
| 고립됐다·춥다 | 역광 림 라이트 + 차가운 색 |
| 신비롭다 | 역광 실루엣. 얼굴을 읽을 수 없게 |
| 무섭다 | 언더 라이트 |
| 취조받는다·압박 | 탑 라이트. 눈이 그늘에 잠긴다 |
| 현실적이다·다큐 | 프론트 소프트. 평평하고 고르게 |
| 숨을 곳이 없다 | 흐린 하늘 확산광 5600K |
| 인물이 산다 | 렘브란트. 뺨에 삼각형 빛 |
| 도시적 | 네온 컬러 대비 + 젖은 바닥 반사 |
| 시적이다·마지막 | 매직아워. 낮게 걸린 해, 긴 그림자 |
| 밤(사실적) | 프랙티컬 중심. 필 없이 어둠을 남긴다 |
| 공기가 보인다 | 볼류메트릭. 헤이즈를 통과하는 광선 |
| 갇혔다 | 고보 그림자. 창살 무늬가 인물을 가로지른다 |

**조명 작성 3원칙**
1. 조명은 03번 블록에서만 선언한다.
2. 광원의 위치를 쓴다. ❌ "분위기 있는 조명" → ⭕ "창 쪽에서 낮게 들어오는 역광"
3. 빛이 만드는 물리 현상을 함께 쓴다 — 입김 · 먼지 · 반사 · 젖은 바닥.

★ 세트 렌더·레퍼런스 이미지가 있으면 그 빛을 먼저 읽고 03번을 쓴다.

## 6. 색 팔레트 3층

| 층 | 역할 |
|---|---|
| 베이스 | 화면의 대부분을 차지하는 배경색 |
| 캐릭터색 | 주인공을 배경에서 분리하는 색 |
| 강조색 | 화면에 아주 조금만 존재하며 시선을 끄는 색 — 하나만 쓴다 |

색은 재료 + 빛 + 역할로 쓴다.
❌ "여자는 빨강을 입는다" → ⭕ "복도의 차가운 빛을 받는 진홍색 실크 스카프"

## 7. 질감 어휘

| 느낌 | 영문 |
|---|---|
| 낡음 | worn textures, weathered and scratched surfaces |
| 새것 | pristine surfaces, factory-new finish |
| 사람 사는 곳 | cluttered lived-in space, scattered personal belongings |
| 비어있음 | minimal sparse interior, few objects |
| 채도 제거 | desaturated palette, muted colors |
| 젖음 | wet reflective surfaces, water beading |
| 추위 | frost crystals, visible breath |
| 더위 | heat haze, sweat-soaked fabric, sun glare |
