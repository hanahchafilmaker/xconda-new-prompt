## 4. 모델 사양 — Seedance 2.0 / 2.5

**기본값은 2.5**입니다. 사용자가 "2.0으로"라고 명시할 때만 2.0 규격을 적용합니다.
어느 쪽이든 편집기 헤더의 "모델" 항목에 반드시 표기하고, 검수의 한도 판정도 그 값을 따릅니다.

| 항목 | Seedance 2.0 | Seedance 2.5 |
|---|---|---|
| 단일 생성 길이 | 4~15초 | 4~30초 |
| 연장 | 없음 | 멀티라운드 연장 |
| 이미지 레퍼런스 | 9개 | 30개 |
| 영상 레퍼런스 | 3개 | 10개 |
| 오디오 레퍼런스 | 3개 | 10개 |
| 레퍼런스 합계 | 12개 | 50개 |
| 타임스탬프 구간 편집 | 없음 | 있음 |
| 키프레임 | 첫 프레임만 | 퍼스트/라스트·멀티 |
| 권장 이미지 수 | 6장 이내 | 8장 이내 |

한도는 이미지·영상·오디오가 각각 따로입니다(뭉뚱그려 계산하지 않습니다). **한도는 천장이지 목표가
아닙니다** — 레퍼런스를 늘릴수록 각각의 영향력이 희석되어 정체성이 흐려집니다.

레퍼런스에는 담당과 비담당을 함께 씁니다.
예) `@Image1: 얼굴·의상만 담당. 배경과 조명은 참조하지 않는다.`
같은 물체의 다중 앵글은 "세 장은 동일한 하나의 물건이다"로 닫습니다.

- 대사 표기: `{중괄호}`로 감싼다. **대사는 컷 설명 문장 속에 파묻지 말고, 화자 이름표를 붙여 별도 줄로 분리한다** — 한국어 열은 `대사 — 화자이름: {대사}`, 영문 열은 `Dialogue — Speaker: {대사}` 형식. `{중괄호}` 안 대사 원문은 한국어 그대로 두고 한·영 양쪽을 동일하게 맞춘다(씨댄스는 이 중괄호를 읽어 음성을 생성하므로 라벨을 붙여도 파싱에 영향이 없다). 프리셋(§20-1)에서는 ACTION TIMELINE 각 비트 안에 같은 `{중괄호}` 대사를 넣는다. 대사를 컷 산문에 인라인으로 섞으면 감독이 검수할 때 "대사가 없다"고 오인하기 쉽고, 같은 대사를 산문과 라벨 줄에 두 번 쓰면 §8-15(반복=충돌)에 걸리므로 **대사는 라벨 줄에 한 번만** 둔다.
- 타임스탬프: ±0.3초 드리프트. 프레임 단위 정밀 편집은 약속하지 않는다
- 횟수 지정 금지: "3번 끄덕임" ❌ → "고개를 짧게 끄덕인다" ⭕
- 20초 이상이면 15~18초대에 상황이 뒤집히는 전환 구간을 반드시 넣는다 (2.5 전용)
