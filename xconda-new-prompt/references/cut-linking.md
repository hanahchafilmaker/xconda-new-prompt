# 멀티컷 컷 연결 6규칙 (구 §10-1)

> 이 파일은 SKILL.md에서 분리된 상세 규칙입니다. SKILL.md의 라우팅 표가 이 파일을 가리킬 때 엽니다.
> 규칙 내용은 원본 그대로이며 위치만 옮겼습니다.

## 10-1. 컷 연결 규칙 — 튀지 않게 잇는다 (멀티컷 전용)

AI 모델은 이전 컷을 기억하지 못합니다. 사람이 편집할 때 눈으로 자연스럽게 잇는 걸
여기서는 **글로 직접 지정**해야 합니다. 멀티컷 모드에서 컷을 2개 이상 쓸 때마다
아래 6가지를 확인합니다. 상세 설명·예시·체크리스트는
`references/cut-continuity.md`에 있습니다 — 프롬프트를 완성한 뒤 한 번 대조하세요.

1. **Cut on Action** — 동작 도중에 컷을 넘긴다. 이어받는 컷은 "(컷N에서 이어)"로
   시작한다 (08번)
2. **30도 & 2단계 규칙** — 같은 인물 연속 컷은 화각 2단계 이상 차이 또는 카메라
   각도 30도 이상 이동, 둘 중 하나를 지킨다 (04번)
3. **180도 가상선** — 인물의 화면 좌우 위치·이동 방향은 컷이 바뀌어도 유지한다
   (01번 또는 08번)
4. **룸톤 연속성** — 같은 공간의 컷들은 환경음이 끊기지 않고 이어진다 (09번)
5. **마이크로 파즈** — 대사 직후 0.5~1초 호흡 여운을 시간까지 명시해 쓴다 (08번)
6. **리액션·인서트 샷** — 대사·액션 컷만 늘어놓으면 길이를 늘려도 리듬이
   죽는다. **대사·액션 컷 2개당 인서트 1개**를 최소선으로 잡고(15초 1~2개 /
   30초 3~4개 / 45초 이상 5개 이상), 각 인서트는 0.8~2초로 짧게 쓴다 (08번)

**길이가 모자란다는 말이 나오면 컷 길이부터 늘리지 않는다.** 먼저 인서트
개수를 센다 — 위 기준에 못 미치면 원인은 길이가 아니라 인서트 부족이다.
씬의 소품·대사 듣는 인물·전조 사물·공간 디테일·손발에서 후보를 뽑아
**목록으로 먼저 보여주고 사용자에게 고르게 한다**(뽑는 법은
`references/cut-continuity.md` §6).

우선순위: 월터 머치의 편집 6원칙에 따르면 감정(51%)·이야기(23%)가 이 기법들보다
우선입니다. 규칙을 다 지켰는데 감정이 안 살면 규칙 쪽을 깨도 됩니다.
